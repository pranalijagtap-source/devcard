# DevCard Generator

A sleek developer profile card generator that pulls live data from the GitHub API and renders it as a shareable, downloadable dev card — styled with a dark/purple theme.

## ✨ Features

- 🔍 Fetches real-time GitHub profile data (avatar, bio, repos, followers, following) via the GitHub API
- 🎨 Dark/purple aesthetic, clean and modern UI
- ⚡ Built with pure HTML, CSS, and JavaScript — no frameworks
- 🌐 Deployed on GitHub Pages
- 📱 Responsive design

## 🛠️ Tech Stack

- **HTML5** — structure
- **CSS3** — styling and dark/purple theme
- **JavaScript** — GitHub API integration and DOM manipulation
- **GitHub API** — fetching user profile data

## 🚀 Live Demo

[https://pranalijagtap-source.github.io/devcard/]


## ⚙️ How It Works

1. Enter a GitHub username
2. The app fetches profile data using the GitHub REST API
3. Data is rendered into a styled card (name, avatar, bio, stats)
4. Card can be viewed, styled, or shared

## 📦 Getting Started

```bash
# Clone the repository
git clone https://github.com/pranalijagtap-source/devcard-generator.git

# Navigate into the project
cd devcard-generator

# Open index.html in your browser
```

No build tools or dependencies required — it's a static site.
